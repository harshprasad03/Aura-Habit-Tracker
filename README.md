# 🌟 Aura Habit Tracker — Gamified Productivity App

Aura Habit Tracker (also called **Aura Farming**) is a Python-based desktop application that transforms habit-building into a rewarding experience. Instead of ticking checkboxes, users earn **Aura Points**, maintain streaks, level-up through six stages, and track their progress using built-in analytics — all within a clean, modern CustomTkinter UI.

This project applies principles from **behavioural design and gamification** to make consistency more engaging and sustainable.

## 🛠 Tech Stack

- **Python 3.x**
- CustomTkinter
- Matplotlib
- Seaborn
- JSON storage
- Pillow (for character assets)

## 🚀 Getting Started

### Install dependencies
```bash
pip install customtkinter matplotlib seaborn pillow
````

### Run the app

```bash
python main.py
```

User data is stored locally in `user_data.json`.
